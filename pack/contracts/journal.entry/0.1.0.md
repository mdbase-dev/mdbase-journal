# Journal entry

A journal entry is one note written at one moment. The contract asks for a
single field, `created`; the entry itself is the record's Markdown body.

Journal writes `created` through this contract and then saves the body with
ordinary whole-record updates. Everything else about an entry belongs to the
type that implements this contract: its field names, extra fields, and the
lifecycle rules that fill them in.
