# Unreleased

- Choosing a date or a saved entry closes the entries dialog and returns focus to the writer.

- The entries sheet now lists saved entries in large collections instead of showing only notes on this device.

- Screen reader users can jump to the current journal date as the page’s main heading. The date still opens the entry picker.

- Local builds and development startup verify the SDK actually pinned by the app, using the same production metadata as publication.

- Keep newer journal text when a delayed change from another tab arrives while you type.

- Editing an entry in two tabs no longer silently overwrites another tab's text. Clean tabs follow saved changes; conflicting writing stays visible with copy and saved-version choices.

- Previous and next day arrows open that day's latest entry directly, or a blank page if it is empty. The date heading still opens the entry picker. Existing text and record identities stay preserved.
